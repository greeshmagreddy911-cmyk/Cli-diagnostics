# Automated Student Report Generator

Python Software Engineering Internship – Task 6.

An end-to-end Python automation application for processing student marks, generating reports, providing a backend API, and supporting automated scheduling and CLI execution.

## Features

- CSV student data processing
- Automatic average calculation
- PASS/FAIL result generation
- JSON report generation
- FastAPI REST API
- Automated report scheduling
- Command-line interface
- Input validation
- Automated tests
- System architecture documentation
