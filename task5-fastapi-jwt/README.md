# FastAPI Microservice with JWT Authentication

Python Software Engineering Internship – Task 5.

This project demonstrates a FastAPI REST API with user registration, login, JWT Bearer authentication, password hashing, Pydantic validation, and secure CRUD operations.

## Features

- User registration
- Secure password hashing
- JWT authentication
- Bearer token authorization
- Pydantic request validation
- Protected CRUD endpoints
- Interactive Swagger documentation at `/docs`
